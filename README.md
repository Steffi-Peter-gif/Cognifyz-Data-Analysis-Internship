# Cognifyz Data Analysis Internship

This repository contains my work from the **Cognifyz Data Analysis Internship**.

I worked with a restaurant dataset and used Python to explore the data, find patterns, and generate useful insights through different analysis tasks.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

## What I Worked On

The project covers different levels of data analysis, including:

- Finding the most common cuisines
- Analyzing restaurants by city
- Studying price range distribution
- Checking online delivery availability
- Exploring restaurant ratings
- Analyzing cuisine combinations
- Looking at restaurant locations
- Studying restaurant chains
- Understanding the relationship between votes and ratings
- Comparing price ranges with service availability

## Files in this Repository

- `Cognifyz_Data_Analysis_Internship.ipynb` — My analysis notebook
- `Dataset .csv` — Dataset used for the analysis

## How I Worked

I completed the analysis using **Google Colab**, with Python, Pandas, and Matplotlib. The notebook contains the code, analysis, and visualizations for the tasks.
